# Portfólio Edardna

Portfólio de página única criado para o narrador esportivo Edardna, reunindo as redes sociais dele e as co-narrações, com link direto para cada vídeo no YouTube.

Feito apenas com HTML e CSS.

## O que tem no site

- Card de apresentação com foto, texto e ícones das redes sociais (Instagram, YouTube, Twitch e Discord)
- Seção de co-narrações com título e imagem clicável para cada vídeo
- Fundo em gradiente verde e roxo

## Tecnologias

- HTML5
- CSS3 (Grid e Flexbox)
- [Font Awesome](https://fontawesome.com/) para os ícones, carregado por CDN
